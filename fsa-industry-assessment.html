業種別支援の着眼点

金融庁委託 / 日本生産性本部・メディアラグ作成 | 金融機関職員向け業種別目利きガイド要約

このレポートについて

  • 金融庁が令和4〜7年度にかけて委託作成した、金融機関職員が中小企業を訪問する際の業種別チェックポイント集
  • 全10業種（飲食・小売・卸売・建設・製造・運送・サービス・医療・介護・宿泊）を網羅
  • 本レポートでは製造業・サービス業・飲食業の3業種を深掘り、他7業種は概観+原典リンク
  • 各業種は「決算資料編」「訪問時編」「工場見学編」等の切り口で構成
松澤の所見: 公的機関が出している網羅的・実践的な資料。中小企業経営者は資金調達コンサルや「あなたのCFO」系サービスに頼る前に、金融機関がどういう目線で見ているかをこの資料で把握すべき。金融機関の営業担当にとっても、支店の先輩・上司の口伝より網羅性がある教科書。商社志望者は日本貿易会へ、お金借りたい人は金融庁へ。
コンセプト（金融庁資料の設計思想）:
  1. 若手職員や経験年数の浅い方々が、現場の実務や支援の初動で使いやすいレベル・分量
  2. 一つの業種において、各項目の内容が一つのスライドで完結する構成
  3. 業種全体の概観を俯瞰できることをめざしている
  4. 本書を出発点として、用途に応じてそれぞれの組織・個人で、内容の追加等の工夫を加えながら活用

中小製造業の目利き 5編構成

決算資料編

CHECK 1
売上総利益
同業他社の業界平均に着目。加工業種ごとの生産粗益をヒアリング。売上総利益にまず注目する。
CHECK 2
売上原価（製造原価）
材料費・労務費・外注費・経費の「割合」に着目。外注費比率の高い企業は外注先の把握が重要。
CHECK 3
固定資産台帳
必ず入手し確認する（製造業・建設業・運送業では必須）。機械類の取得年月日に着目。インターネットで調べると工場内の機能の特性が分かる。
CHECK 4
固定長期適合率
固定資産÷(固定負債+自己資本) = 100%以下が目安。固定負債に運転資金が入っていないか確認。固定資産の内訳を確認してから計算する。

訪問時編

CHECK 1
生産体制の確認
労働集約型（手作業中心）vs 資本集約型（自動化中心）。
労働集約型 → 人材に関する着眼点が中心（社員定着率、パート比率、多能工化）。
資本集約型 → 設備に関する着眼点が中心（設備の性能・状況、余剰スペース）。
CHECK 2
生産形態の確認
受注生産が中心か、見込み生産か、連続生産か。生産フォームによって在庫や資金繰りへの影響が異なる。
CHECK 3
流通経路の確認
自社完結型か、下請中心か、商社仲介型か。製品企画→設計→資材調達→製造→運送→販売のどこまでを請け負っているか。
CHECK 4
元請からの依存度（信頼度合）
「元請への依存度」ではなく「元請からの依存度（信頼度合）」の確認。昨今は下請に蓄積された知見・技術に元請が依存する傾向。
「この仕事で一人前になるのに、どのくらいかかりますか？」 — 深い専門知識がなくても技術の高さを見極める有効な質問。

工場見学編

VIEW 1
在庫の確認
財務諸表だけで判断しない、金額だけで判断しない。生産形態（見込み/受注×連続/個別）と在庫の関係を理解する。
VIEW 2
生産形態の確認
4つの視点: 生産現場のポイントを押さえた視察、組織図の確認、生産工程の視察、整理整頓の確認。
VIEW 3
5秒×10回診断
1人の工員を5秒ごとに10回観察。直接作業の回数を数える。6〜7回以上なら「良い」。
VIEW 4
日付と修正に注目
工場内の資料の日付バラツキ、手書き修正の度合いを確認。

マッチング編

軸内容
サイズ製造可能なサイズ・ロットの適合性を確認し、取引先とのマッチングを支援
数量最低ロット・大量生産対応力を把握し、需要側とのすり合わせを行う

将来の事業性・成長の可能性

ISSUE 1
国内回帰への対応
製造の国内回帰ニーズ。引き合いがあるか、ヒト・モノ・カネの課題はないか。
ISSUE 2
環境問題への対応
製造品・設備の環境対応、廃棄物処理。
ISSUE 3
値上げ交渉への対応
金融機関として値上げ交渉の支援ができる。
ISSUE 4
人材不足への対応
外国人材との良好な関係構築。

中小サービス業の目利き 宿泊等の大型装置系を除く

訪問前編 — 他業種との関連性

TYPE A
設備的サービス
スポーツジム・コインランドリー・リース業等。設備や機械が競争力に直結、稼働率・個別採算・保守費用に着目。
TYPE B
属人的サービス
理容・美容・クリーニング・小規模クリニック等。人に売上（顧客）が直接つく、従業員の出入りが業績に直結。
サービス業は非常に広範な業態を含むため、業態によって着眼するポイントが大きく異なる。代表的なサービス業がどの業種（製造業、飲食業、小売業、卸売業、建設業、運送業）と類似点があるかを把握し、関連業種の着眼点も合わせて活用するとよい。

決算資料編

CHECK 1
売上高営業利益率（本業収益力）
労働集約的な業態が多いので、営業利益にまず着目。人件費・地代家賃・水光熱費が大きなウェイトを占める。
CHECK 2
売上高の傾向
売上の傾向と人件費の変化の相関を確認。大きな変化がある場合は人の出入りやサービスの質の変化の可能性。
CHECK 3
当座比率
100%以上なら良好。短期借入金の急激な変動がないかチェック。小規模事業が多いため資金繰りは比較的読みやすい。

訪問時編

CHECK 1
人材の内訳
正社員・パートの人数と役割分担、勤務年数、必要な資格保有者の確認。
CHECK 2
売上高の傾向（訪問時）
本業以外の物販・副業収入も確認。競合との比較。
CHECK 3
顧客情報管理
属人的サービスでは固定客が支え。リピート率、顧客管理の整備状況、SNS活用。
CHECK 4
人と組織風土の目安
平均年齢×勤務年数の4象限マトリクスで組織の特性を把握する。

中小飲食業の目利き 家族経営中心

基本原則・商圏

「安い」「近い」と、どのように戦っていくか？ — 大手チェーンは低価格・好立地。中小飲食業は味・接客・専門性・店舗造り・サービスで対抗する。消耗戦にならない経営が重要。

商圏の目安

商圏範囲移動手段感覚
1次商圏半径350〜500m徒歩15分以内500〜700歩、自転車2〜3分
2次商圏半径3〜4km自転車15分以内歩くと1時間前後
3次商圏半径15km以内車30分以内音楽を6〜7曲聞いて到着
商圏の体感法: 「故郷から久々に親友が遊びに来た」というストーリーで商圏を体感する。「歩いて何分ならここに連れていくか？」「車で30分かけてくる品揃えやサービスだろうか？」— 飲食業の事業性は日常生活の感覚で把握できる。

決算資料編

CHECK 1
原価率
業態別目安: かき氷・ハイボール≅20%、餃子・ケーキ≅30%、ラーメン・ビール≅30%、高級・こだわり店≅35%。お店のイメージと原価率の均整に注目。
CHECK 2
人件費の内訳
「何人くらいの社員・パートが雇われているか」に着目。計算上の人件費と実態の乖離（特に個人事業主）。
CHECK 3
FL比率
F(材料費)+L(人件費)÷売上高。60%以下を目指す。FLコスト60%+その他経費30%+営業利益10%が理想。

訪問時編

CHECK 1
役割分担と人数
誰がどの役割か。決算書の人件費と実際の人数に乖離がないか。材料費削減（オーバーポーション防止、仕入先見直し）と人件費（シフト最適化、客席回転率）。
CHECK 2
客数
客数データはあるか。時間帯別・曜日別管理。「客数×客単価」の把握が重要。
CHECK 3
面積・席数
厨房と客席の比率、席数密度。レストランは厨房40%客席60%、普通食堂は厨房20%客席80%。

COREWO業務への活用ポイント

USE CASE 1
顧客訪問前の予習
業種に応じたチェックリストとして活用。何を見て何を聞くべきかが明確になる。
USE CASE 2
補助金申請支援
金融機関の視点を踏まえた事業計画書が書ける。認定支援機関としての確認書発行もスムーズに。
USE CASE 3
決算前MTG
業種の着眼点を踏まえて分析すれば、より本質的な議論ができる。
USE CASE 4
地銀向け提案
金融機関職員が日常的に使うべきフレームワークとして、提案資料に組み込める。
補助金採択ダッシュボードとの接続: 本資料の業種別チェックポイントは、補助金の事業計画書における「事業の現状分析」「課題の特定」パートと直結する。
