業種別支援の着眼点

金融庁委託 / 日本生産性本部・メディアラグ作成 | 金融機関職員向け業種別目利きガイド要約

このレポートについて

  • 金融庁が令和4〜7年度にかけて委託作成した、金融機関職員が中小企業を訪問する際の業種別チェックポイント集
  • 全10業種（飲食・小売・卸売・建設・製造・運送・サービス・医療・介護・宿泊）を網羅
  • 本レポートでは全10業種の目利きポイントを要約（各業種の原典PDFリンク付き）
  • 各業種は「決算資料編」「訪問時編」「工場見学編」等の切り口で構成

　 金融庁が生産性本部に委託して作った「業種別支援の着眼点」。中小企業の皆さんは資金調達コンサルとか「あなたのCFO」とかに頼る前に、金融機関がどういう目線で見てるのかを自分で見て、考えた方がいい。
コンセプト（金融庁資料の設計思想）:
  1. 若手職員や経験年数の浅い方々が、現場の実務や支援の初動で使いやすいレベル・分量
  2. 一つの業種において、各項目の内容が一つのスライドで完結する構成
  3. 業種全体の概観を俯瞰できることをめざしている
  4. 本書を出発点として、用途に応じてそれぞれの組織・個人で、内容の追加等の工夫を加えながら活用

中小製造業の目利き 5編構成

決算資料編

CHECK 1
売上総利益
同業他社の業界平均に着目。加工業種ごとの生産粗益をヒアリング。売上総利益にまず注目する。
CHECK 2
売上原価（製造原価）
材料費・労務費・外注費・経費の「割合」に着目。外注費比率の高い企業は外注先の把握が重要。
CHECK 3
固定資産台帳
必ず入手し確認する（製造業・建設業・運送業では必須）。機械類の取得年月日に着目。インターネットで調べると工場内の機能の特性が分かる。
CHECK 4
固定長期適合率
固定資産÷(固定負債+自己資本) = 100%以下が目安。固定負債に運転資金が入っていないか確認。固定資産の内訳を確認してから計算する。

訪問時編

CHECK 1
生産体制の確認
労働集約型（手作業中心）vs 資本集約型（自動化中心）。
労働集約型 → 人材に関する着眼点が中心（社員定着率、パート比率、多能工化）。
資本集約型 → 設備に関する着眼点が中心（設備の性能・状況、余剰スペース）。
CHECK 2
生産形態の確認
受注生産が中心か、見込み生産か、連続生産か。生産フォームによって在庫や資金繰りへの影響が異なる。
CHECK 3
流通経路の確認
自社完結型か、下請中心か、商社仲介型か。製品企画→設計→資材調達→製造→運送→販売のどこまでを請け負っているか。
CHECK 4
元請からの依存度（信頼度合）
「元請への依存度」ではなく「元請からの依存度（信頼度合）」の確認。昨今は下請に蓄積された知見・技術に元請が依存する傾向。
「この仕事で一人前になるのに、どのくらいかかりますか？」 — 深い専門知識がなくても技術の高さを見極める有効な質問。

工場見学編

VIEW 1
在庫の確認
財務諸表だけで判断しない、金額だけで判断しない。生産形態（見込み/受注×連続/個別）と在庫の関係を理解する。
VIEW 2
生産形態の確認
4つの視点: 生産現場のポイントを押さえた視察、組織図の確認、生産工程の視察、整理整頓の確認。
VIEW 3
5秒×10回診断
1人の工員を5秒ごとに10回観察。直接作業の回数を数える。6〜7回以上なら「良い」。
VIEW 4
日付と修正に注目
工場内の資料の日付バラツキ、手書き修正の度合いを確認。

マッチング編

軸内容
サイズ製造可能なサイズ・ロットの適合性を確認し、取引先とのマッチングを支援
数量最低ロット・大量生産対応力を把握し、需要側とのすり合わせを行う
エリア地理的な商圏・配送可能圏を踏まえたマッチング

将来の事業性・成長の可能性

ISSUE 1
国内回帰への対応
製造の国内回帰ニーズ。引き合いがあるか、ヒト・モノ・カネの課題はないか。
ISSUE 2
環境問題への対応
製造品・設備の環境対応、廃棄物処理。
ISSUE 3
値上げ交渉への対応
金融機関として値上げ交渉の支援ができる。
ISSUE 4
人材不足への対応
外国人材との良好な関係構築。

中小サービス業の目利き 宿泊等の大型装置系を除く

訪問前編 — 他業種との関連性

TYPE A
設備的サービス
スポーツジム・コインランドリー・リース業等。設備や機械が競争力に直結、稼働率・個別採算・保守費用に着目。
TYPE B
属人的サービス
理容・美容・クリーニング・小規模クリニック等。人に売上（顧客）が直接つく、従業員の出入りが業績に直結。
サービス業は非常に広範な業態を含むため、業態によって着眼するポイントが大きく異なる。代表的なサービス業がどの業種（製造業、飲食業、小売業、卸売業、建設業、運送業）と類似点があるかを把握し、関連業種の着眼点も合わせて活用するとよい。

決算資料編

CHECK 1
売上高営業利益率（本業収益力）
労働集約的な業態が多いので、営業利益にまず着目。人件費・地代家賃・水光熱費が大きなウェイトを占める。
CHECK 2
売上高の傾向
売上の傾向と人件費の変化の相関を確認。大きな変化がある場合は人の出入りやサービスの質の変化の可能性。
CHECK 3
当座比率
100%以上なら良好。短期借入金の急激な変動がないかチェック。小規模事業が多いため資金繰りは比較的読みやすい。

訪問時編

CHECK 1
人材の内訳
正社員・パートの人数と役割分担、勤務年数、必要な資格保有者の確認。
CHECK 2
売上高の傾向（訪問時）
本業以外の物販・副業収入も確認。競合との比較。
CHECK 3
顧客情報管理
属人的サービスでは固定客が支え。リピート率、顧客管理の整備状況、SNS活用。
CHECK 4
人と組織風土の目安
平均年齢×勤務年数の4象限マトリクスで組織の特性を把握する。

中小飲食業の目利き 家族経営中心

基本原則・商圏

「安い」「近い」と、どのように戦っていくか？ — 大手チェーンは低価格・好立地。中小飲食業は味・接客・専門性・店舗造り・サービスで対抗する。消耗戦にならない経営が重要。

商圏の目安

商圏範囲移動手段感覚
1次商圏半径350〜500m徒歩15分以内500〜700歩、自転車2〜3分
2次商圏半径3〜4km自転車15分以内歩くと1時間前後
3次商圏半径15km以内車30分以内音楽を6〜7曲聞いて到着
商圏の体感法: 「故郷から久々に親友が遊びに来た」というストーリーで商圏を体感する。「歩いて何分ならここに連れていくか？」「車で30分かけてくる品揃えやサービスだろうか？」— 飲食業の事業性は日常生活の感覚で把握できる。

決算資料編

CHECK 1
原価率
業態別目安: かき氷・ハイボール≅20%、餃子・ケーキ≅30%、ラーメン・ビール≅30%、高級・こだわり店≅35%。お店のイメージと原価率の均整に注目。
CHECK 2
人件費の内訳
「何人くらいの社員・パートが雇われているか」に着目。計算上の人件費と実態の乖離（特に個人事業主）。
CHECK 3
FL比率
F(材料費)+L(人件費)÷売上高。60%以下を目指す。FLコスト60%+その他経費30%+営業利益10%が理想。

訪問時編

CHECK 1
役割分担と人数
誰がどの役割か。決算書の人件費と実際の人数に乖離がないか。材料費削減（オーバーポーション防止、仕入先見直し）と人件費（シフト最適化、客席回転率）。
CHECK 2
客数
客数データはあるか。時間帯別・曜日別管理。「客数×客単価」の把握が重要。
CHECK 3
面積・席数
厨房と客席の比率、席数密度。レストランは厨房40%客席60%、普通食堂は厨房20%客席80%。

中小小売業の目利き 差別化が鍵

基本原則・商圏

「安い」「近い」と、どのように戦っていくか？ — 大手チェーンは低価格・好立地。中小小売業は趣味性の高い品揃え・接客・専門性・サービスで対抗。小売業は自ら品質や味で差別化を創造することが困難なため、消耗戦にならない経営が特に重要。
商圏範囲移動手段対象
1次商圏半径350〜500m徒歩15分コンビニ・小規模小売店
2次商圏半径3〜4km自転車15分家電量販店
3次商圏半径15km以内車30分非常に有名な専門店

決算資料編

CHECK 1
総資本回転率
3年程度の傾向で事業健全性を確認。自社物件か賃貸物件かにより数値が変化するため、業界平均よりも個社別の傾向・変化に注意。
CHECK 2
売上高総利益率
取扱品目により大きく変化。業態別目安: 機械機器25%、スーパー26%、飲食料品32%、繊維・衣服45%。
CHECK 3
経常利益（リベート）
メーカーや問屋からのリベート（雑収入）に注意。営業利益は赤字でもリベートで経常利益は黒字というケースが一定数存在。

訪問時編

CHECK 1
売場面積
従業員1人当たり管理可能な売場面積: 目安8〜10坪程度（業種・業態で変動）。
CHECK 2
取扱アイテム数
従業員1人当たり管理可能数: 目安80〜100アイテム。売場面積とアイテム数を把握した上で、実行不可能な提案を避ける。
CHECK 3
売上高構成式
売上高 = 客数(入店客数×買上率) × 客単価(平均買上点数×平均商品単価)。詳細データがない場合はレジ件数等から推計。
CHECK 4
差別化の3類型
専門性（マニア・プロ向け商材）、保守修繕（修理・セットアップ・メンテ）、関係性（嗜好把握・クラブ的つながり・SNS交流）。

中小卸売業の目利き 3機能が鍵

決算資料編

CHECK 1
売上高営業利益率
本業収益力を確認。売上高粗利益率の構成と推移がポイント。業界平均はあくまで「目安」であり「優劣の基準」ではない。
CHECK 2
棚卸資産回転日数
棚卸資産÷(売上高÷365日)。「回転率」より「日数」や「月数」で現場と会話するとよい。
CHECK 3
総資本回転率
自社倉庫を所有する地域の卸売業では特に重要。不動産が関わるため有利子負債にも要注意。
CHECK 4
自社物件 vs 賃借物件
事業用倉庫の形態が決算に与える影響を把握。売却やリースバック等の出口戦略も検討対象。

訪問時編 — 求められる3つの機能

1
待てる機能
「支払い」を待てる金融機能 + 「発注」を待てる受注機能。FAX・電話・メール等で柔軟に対応。
2
分ける機能
バラ単位での納品を継続。最低発注ロットの大型化が進む中、地元小規模業者から「選ばれる」存在。
3
運べる機能
地域の隅々まで配送し、現場での積み下ろし（ユニック車等）まで対応。

在庫削減の安易な適用は危険: 「仕入はケース単位、販売はバラ単位」が業界の当たり前。大手の効率化をそのまま中小に適用すると、地元取引先から求められる現実的な機能を低減させてしまう。

中小建設業の目利き 3編+事業性

決算資料編

CHECK 1
売上総利益（完成工事利益）
工事種類ごとの受注割合をヒアリングし、加重平均で業界平均と比較。例: 土木40%・住宅60%で加重平均。
CHECK 2
売上原価（完成工事原価）
材料費・労務費・外注費・経費の「割合」に着目。外注費割合が大きい場合は外注先ネットワークが工事の元請け。
CHECK 3
固定資産台帳
必ず入手。機械・車両の形式をネット検索すると施工分野や強みを把握できる。
CHECK 4
立替工事高比率
目安11〜13%（約1.5ヶ月分）。中小建設業ほど高くなる傾向。未成工事支出金にも要注意。

訪問時編

CHECK 1
工事施工体制
集権型（トップが全て選定）vs 分権型（現場代理人に委任）。それぞれの長所・短所を理解し改善に着手。
CHECK 2
工事種別・受注形態
官公庁vs民間、元請vs下請の割合マトリクス。受注形態を理解せずに提案しても響かない。
CHECK 3
キーマンの把握
現場代理人・技術者数、積算担当者（受注と予算の要）、営業担当者、作業員名簿（年齢・資格・勤続年数）。
CHECK 4
静態観察
資材置き場の整備状況、工事車両の清掃状況、表彰状・感謝状。早朝・休日の静態観察が効果的。

将来の事業性

好循環プロセス: 積算・見積 → 落札受注 → 実行予算 → 原価管理。この循環が機能しているかが事業性の「カギ」。予算や原価の管理体制が不十分だと、工事代金回収よりも先に窮境に陥る。

中小運送業の目利き 人材が命

決算資料編

CHECK 1
速算的な平均純利益額
(純資産−資本金)÷決算期数で数期の業績傾向を大まかに把握。
CHECK 2
固定長期適合率
車両が主な固定資産。100%を超えていないか確認。超えている場合は仕事の質・量に課題の可能性。
CHECK 3
運転手1名当たり運送収入
運送収入÷運転手数。人材不足の中での最低限の売上維持の目安。
CHECK 4
売上高営業利益率
中小運送業は運送原価と販管費が区分されていないことが多い。損益計算書の構造に要注意。

訪問時編

CHECK 1
運転手の内訳
人数・年齢・資格。運転手台帳を確認。高齢化や若者不足が深刻。
CHECK 2
キーマン: 配車係
建設業の積算担当者と同じく最重要キーマン。配車係の手腕で売上規模・収益が変わる。荷主企業の詳細を最もよく知る存在。
CHECK 3
特殊車両への注目
主業と異なる分野の車両（例: ダンプ会社に1台だけある冷凍車）が高収益部門やボトルネックになっていることがある。
CHECK 4
静態観察
早朝・休日に車両の駐車状況や清潔感を観察。車両の稼働率や管理状況が把握できる。
運送業用語: ベタ降ろし（手作業で一個ずつ降ろす）、バラ積み（一個ずつ積み込み）、横持ち（横展開で移動）、車上渡し・置き場渡し（荷役範囲を決定）

小規模医療業の目利き 診療所が対象

対象: 医療法で「診療所」と区分される医療機関（入院ベッド19床以下または無し）。医療行為自体への助言は困難という割り切りが必要。事業構造の理解や財務視点での提言が中心。

中小介護業の目利き 人件費60-70%

基本編

介護業の収益構造: 介護保険収入がほとんどで原価はほぼ発生しないため、収入≈粗利益。「人と人」を中心とした業務であり、人員配置基準により一定人数が必要。規模や範囲の経済に合致した事業所になりやすい。
TYPE A
入居系サービス
特養・老健・サ高住・有料老人ホーム。人によるサービスに加えて施設利用がサービスの中心。投資に対する個別採算が重要。
TYPE B
在宅系サービス
訪問介護・通所介護(デイサービス)・短期入所(ショートステイ)・訪問看護。人やサービスの評価が収入を左右。従業員の出入りが業績に直結。

決算資料編

CHECK 1
介護事業収入の推移
数年分の推移を把握。利用者数等は訪問時にヒアリング。同一地域の事業関係者との連携で情報収集も有効。
CHECK 2
人件費と収支
人件費率60〜70%前後が目安。訪問介護72%、通所介護64%、特養65%。人員配置基準により変動費化が困難。

訪問時編

CHECK 1
延べ利用者数
利用者を集められるかが最大のポイント。事業収入 = サービス単価×利用者数×稼働率。
CHECK 2
人員の内訳
正社員・パートの別、資格者、平均勤務年数。退職原因は小さな不満の積み重ね（コミュニケーション・業務量・休暇）。
CHECK 3
生産性向上
人時生産性(粗利益÷総労働時間)の向上がポイント。見守りセンサー・ケア記録ソフト・インカム・介護ロボット等のテクノロジー導入。
経営者タイプ3類型: ①業務拡大を続ける経営者（体力に見合わない投資に注意）、②人が集まる経営者（属人的つながりで人材確保）、③ボランティア精神が強い経営者（十分な報酬を得ていない場合も）

中小宿泊業の目利き 設備が命

決算資料編

CHECK 1
固定長期適合率
100%以下が目安。景気変動・季節変動に大きく影響を受ける。数値が良好でも主要設備の老朽化確認は必須。
CHECK 2
償却前営業利益
返済能力の判断指標。事業継続に必要な設備投資支出（配管・ボイラー等）を確認した上で判断する。
CHECK 3
1期当たり平均純利益
純資産÷業歴。景気変動が大きいため2〜3期だけの分析で判断しないこと。

訪問後編

RevPAR（Revenue Per Available Room）= 客室稼働率 × 客室平均単価。宿泊販売の最も基礎的な指標。繁忙期の数値悪化は空室を売り切る力がないことを示し、閑散期の数値上昇は隠れたニーズの存在を示唆する。
