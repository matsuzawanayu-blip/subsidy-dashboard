業種別支援の着眼点

金融庁委託 / 日本生産性本部作成 | 金融機関職員向け業種別目利きガイド要約 | 2026-04-20

このレポートについて

  • 金融庁が日本生産性本部に委託して作成した、金融機関職員が中小企業を訪問する際の業種別チェックポイント集
  • 本レポートでは建設業（訪問時編）・卸売業（訪問時編）・製造業（工場見学編）の3業種を要約
  • 各業種ごとに「何を見るか」「何を聞くか」「どう判断するか」の実践的な着眼点が体系的にまとまっている
  • 中小企業経営者自身が「金融機関はこう見ている」と理解するための教材としても有用
なぜこの資料が重要か: 公的機関が出している網羅的・実践的な資料。中小企業経営者は資金調達コンサルや「あなたのCFO」系サービスに頼る前に、金融機関がどういう目線で見ているかをこの資料で把握すべき。金融機関の営業担当にとっても、支店の先輩・上司の口伝より網羅性がある教科書。商社志望者は日本貿易会へ、お金借りたい人は金融庁へ。

中小建設業の目利き 訪問時編

会社を訪問する際に、どのようなことに目を凝らし、何を聞けばよいか分からないという質問が多い。企業の事業性や経営改善の可能性を判断するのに必要な、基本的なポイントをまとめる。

1. 工事施工体制

TYPE A
集権型
トップや特定の人物が受注額・予算額・取引先・建材・下請業者を選定。現場は"受け身"で施工を行うことに専念する運営が中心。
TYPE B
分権型
請負った仕事は原則として現場代理人が取引先・建材屋・下請業者を選定。場合により営業の一部も現場に任せる運営もある。
着眼ポイント:
  • 集権型: 資材価格や発注先・業者選定まで本社やトップの決定権。一定の管理がなされる反面、受注する力がないと下請業者が離れていく。請負金額の低い工事等では現場の負担が増え、士気低下による収益力の悪化に繋がるリスク
  • 分権型: 実行予算を現場代理人が作成しても「予算会議」等にかけられるか確認。長所は人的ネットワーク構築・現場の共有意識、短所は予算や原価管理が甘くなりがち
  • 金融機関は企業に「管理」を求めがちだが、あらゆる「管理」を強いると長所を殺す。集権型・分権型それぞれの長所・短所を理解し、事実確認を積み重ねて改善に着手すること

2. 工事種別・受注形態

どのような工事種別の仕事が多いか？ 建設業にも様々な工事種別があり（電気工事・屋根工事・塗装工事等）、土木工事にも道園工事・解体工事・舗装工事等に区分される。

なぜ重要か: 工事種別や受注形態を理解せずに「地元に向けた提案営業力の強化」等を提案しても全く響かないケースがある。工事種別ごとに利益率は異なり、元請・下請の受注割合や官公庁・民間の受注比率を把握することが不可欠。

3. キーマンの把握

確認項目確認すべき内容リスクシグナル
現場代理人・技術者建設業の種類ごとの施工管理技士、設計士等の人数技士の数に限り → 指名発注が来にくくなる
積算担当者経歴（積算は受注と予算の要）定年前で後任なし → 積算精度は経験値に比例
営業担当者経歴（営業は特に民間工事・下請工事確保の要）豊富な工事経験がない → 機動的受注困難
作業員名簿年齢・保有資格・勤続年数 → 施工能力の確認高齢化・流動化 → 施工能力・モチベーション低下
積算担当者のチェックは特に重要: 中小建設業では現場業務を精通したベテランが従事していることが多い。積算担当者が定年間近なのに後任がいないケースでは、明確な役割分担がなかったり、「延々と積算に従事しているか」の経緯を含めた確認が事業性を把握するうえで重要。

4. 静観察

CHECK 1
資材置き場の整備状況
資材が管理整備されているかで、企業の風土や現時点における土台の高低等を推測できる。
CHECK 2
工事車両の駐車状況・清掃状況
車両の管理状態は企業全体の管理水準を反映する。
CHECK 3
社内の表彰状・感謝状
取引先との関係性、会社の強み、受賞時期から年代感も読み取れる。
TECHNIQUE
静態観察
早朝・休日等に会社の外から観察する手法。日中の事務所訪問では本業活動を見られない。運営の実態を側面から推し量るのに効果的。

中小卸売業の目利き 訪問時編

卸売業は、その規模感や都市部・地方等の立地、属する業界によって事業性が大きく異なる。ここでは、一般的な中小規模の卸売業全般の事業性や定性的な目利きのポイントをまとめる。

中小卸売業に求められる「3つの機能」

1
待てる機能
「支払い」を待てる = 金融機能。十分な経営資源がない中小事業者への融通

「発注」を待てる = 受注機能。大手のEOS締切と違い、FAX・電話・メール等で柔軟に対応
2
分ける機能
流通の寡占化で「最低発注ロット」がバラ→ケース→大サイズ化が進む中、バラ単位での納品を継続してくれる存在。地元小規模業者からの「選ばれる」事業者。
3
運べる機能
地方の配送困難・建設業の高齢化で、地域の隅々まで配送し、現場での積み下ろし（ユニック車等）まで対応できる能力。

事業性の見極め公式

待てる機能
+
分ける機能
+
運べる機能
+
後継者候補
=
生存者利益確保

流通の寡占化が進む業界特性の中で、3つの機能を維持し、後継者を絡めた長期的事業継続力で商圏内の生存者利益を得られるかが事業性を計る大きなカギ。

自社便による配送機能の継続性はあるか？（運転手の高齢化、車両の老朽化等）

支援時の留意点

在庫削減の安易な適用は危険:
  • 「不良在庫」「在庫削減」にすぐ目が向きがちだが、「仕入はケース単位、販売はバラ単位」が当たり前の業界。業界特性を精緻に分析せず業界平均と比較して不良在庫を割り出すのは危険
  • 大手のサービスや品揃えの効率化をそのまま中小に適用すると、地元取引先から求められる現実的な機能（待てる・分ける・運べる）を低減させてしまう
  • 自社物件の活用方法や借物件の地代家賃負担を十分に勘案し、少しでも収支や財務負担（借換等の提案による返済負担低減を含む）の改善を試みる捉え方がポイント

中小製造業の目利き 工場見学編

工場見学は、案内されるまま工場内を見て回る中で、矢継ぎ早に色々な機械の説明を受け、聞きなれない言葉や機械音に圧倒されてしまい、結局何も目利きに繋がらなかったというケースも多い。ここでは、専門知識が少ない金融機関職員が見学の際に目利きを行う初歩的なポイントを紹介する。

1. 在庫の確認

大原則:
  • 在庫の多寡を財務諸表だけで判断しない（在庫はビジネスモデルで決まることもある）
  • 在庫の多寡を金額だけで判断しない（数量が減っていても材料単価が高騰している場合もある）

2. 生産形態の確認（4つの視点）

VIEW 1
生産現場の視察
ポイントを押さえて行う。漫然と見学するだけでは何も理解できない。
VIEW 2
組織図の確認
組織図があれば確認する。生産現場の俯瞰的な理解が進み、生産工程視察のロードマップにもなる。
VIEW 3
生産工程の視察
単に工場と設備の説明を受けるのではなく、生産工程の説明を受け可能な限りの理解を深める。
VIEW 4
整理整頓の確認
工場視察時に随所の整理整頓状況を確認する。生産効率と直結することが多い。

3. 5秒 × 10回診断

工場の生産改善提案のための現場観察手法:
  1. 1人の工員の作業に注目する
  2. 注目した工員の作業を5秒ごとに見る、を10回繰り返す
  3. 「直接作業」を行っている回数を数える
  4. おおむね10回中6〜7回以上「直接作業」に従事していれば、初見としては「良い」とする

10回

6-7回
直接作業に従事していれば「良い」
「直接作業」とは: その工員の本来業務。例えば洋服の縫製工であればミシンで縫製をしていることが「直接作業」。移動、待機、探し物、段取り替え等は「間接作業」。中小企業では6〜7回直接作業に従事しているのは結構な水準。大手企業の高度な生産管理とは別の文脈で見る。

4. 日付と修正に注目する

確認対象着眼ポイント読み取れること
日付 作業指示書・伝票・伝言メモ・品質管理報告・機械点検表等の日付を確認。過去・未来にどのくらいバラツキがあるか 見学日が5/15なのに伝票の納期が4月 → 生産の遅れが生じている可能性
手書き修正 作業指示書や伝票等の印刷物が手書きで修正されている度合いを見る 修正が多い → 生産予定や生産計画が頻繁に変更されている。社内の情報伝達に問題がないか
貼り紙・伝言メモ 材料・製品に添付された紙、ホワイトボードに貼られた紙やメモ 放置されたメモ → 情報共有の仕組みや管理の成熟度を示す

決算が良い
注意すべき工場の見え方
整然としていない状態を「活気がある」と捉えるな。口が規格外品の多さや「忙しさ」を見せる場合は要注意。
決算が悪い
注意すべき工場の見え方
整然としていても「受注不足」と安易に捉えるな。「忙しさ」の裏が非効率な生産現場に見えるケースもある。
事前の決算分析は大切だが: 財務分析で先入観を持ちすぎると、現場で得られる情報さえ見逃すことがある。定量面と定性面の目利きのバランスに注意して下さい。

COREWO業務への活用ポイント

USE CASE 1
顧客訪問前の予習
業種に応じたチェックリストとして活用。訪問時に何を見て何を聞くべきかが明確になる。建設業なら施工体制の型、卸売業なら3機能の充足度、製造業なら在庫と生産形態を事前に整理。
USE CASE 2
補助金申請支援
事業計画策定の際に、金融機関の視点を踏まえた計画書が書ける。金融機関が納得する粒度で事業性を説明することで、認定支援機関としての確認書発行もスムーズに。
USE CASE 3
決算前MTG
顧客の業種に応じた着眼点を踏まえて分析すれば、より本質的な議論ができる。数字だけでなく、業種特有の構造的課題を理解した上での提案が可能に。
USE CASE 4
地銀向け提案
金融機関職員が日常的に使うべきフレームワークとして、ダッシュボード等の提案資料に組み込める可能性。補助金採択分析と組み合わせた業種×支援の提案に発展。
補助金採択ダッシュボードとの接続: 本資料の業種別チェックポイントは、補助金の事業計画書における「事業の現状分析」「課題の特定」パートと直結する。例えば製造業の「5秒×10回診断」で課題を特定し、その改善のための設備投資を補助金で賄う――という流れは、補助金申請の王道パターン。
